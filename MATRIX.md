# Provider endpoint inventory

## Routing matrix (actual installed versions, 2026-11-02)

Base B means the allocated http://127.0.0.1:PORT origin; V means B/v1. All keys below are the fixed synthetic-mock-key-129. Environment names and JSON/TOML keys are OS-independent. Linux/macOS configuration uses the isolated HOME; Windows uses isolated USERPROFILE plus HOME and XDG/APPDATA/LOCALAPPDATA overrides. POSIX export X=value, PowerShell $env:X='value', and CMD set X=value are equivalent; the harness supplies an environment map rather than quoting a shell. Windows npm wrappers resolve to the installed package bin entry (native executable when applicable, Node otherwise), preserving empty and JSON arguments.
